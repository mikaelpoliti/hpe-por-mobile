HPE Parts Manager för iPhone

Detta är en PWA (webbapp) som kan installeras på hemskärmen.

VIKTIGT:
iPhone kräver att appen ligger på en HTTPS-webbadress för att fungera korrekt som installerad app.
Ladda upp hela mappen till exempelvis GitHub Pages, Netlify eller företagets egen webbserver.

Installera på iPhone:
1. Öppna webbadressen i Safari.
2. Tryck på Dela-symbolen.
3. Välj Lägg till på hemskärmen.
4. Tryck Lägg till.

Appen kan sedan öppnas som en vanlig iPhone-app och fungerar även offline efter första öppningen.

Data:
- Data och bilder lagras lokalt på iPhone.
- Använd Säkerhetskopia regelbundet.
- Radera inte webbplatsdata innan en säkerhetskopia har sparats.
